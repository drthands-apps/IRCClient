Política de Privacidad

Transparencia total. Cero recolección de datos.

1. Compromiso de No Recolección

FenixIRC es un proyecto de código abierto y sin fines de lucro. Nuestra filosofía es simple: Tus datos son tuyos.

La aplicación no recolecta, almacena ni transmite ningún tipo de información personal, identificadores de dispositivo, registros de chat o credenciales a nuestros servidores. Todo el procesamiento de datos ocurre localmente en tu dispositivo o se envía directamente a los servidores IRC que tú elijas configurar.

2. Uso de Permisos

FenixIRC solicita permisos mínimos necesarios para funcionar:

  • Internet: Para conectarse a las redes IRC.
  • Micrófono (Versión Pro): Solo para la grabación de mensajes de voz cuando el usuario lo activa manualmente.
  • Almacenamiento: Para guardar logs de chat (opcional) y archivos recibidos localmente.

3. Enlaces y Servicios de Terceros

Al utilizar IRC, los mensajes pueden contener enlaces. FenixIRC ofrece un "Modo Aislamiento" que permite bloquear cualquier comunicación externa fuera del protocolo IRC. Si decides subir archivos multimedia (Pro), estos se envían a proveedores externos (Catbox/Litterbox) bajo sus propias políticas de privacidad. FenixIRC no tiene control sobre esos archivos una vez subidos.

4. Seguridad (Cifrado)

La versión Pro incluye cifrado de extremo a extremo (AES-256) para mensajes privados. Las llaves de cifrado se generan en tu dispositivo y nunca abandonan el mismo excepto durante el apretón de manos inicial con tu destinatario.
